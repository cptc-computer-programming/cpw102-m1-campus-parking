# Lab Instructions

This project is organized into phases. Complete each phase in order and use the documents in each folder to guide your work.

## 1. Fork the Repository

Fork the assignment repository to your own GitHub account.

Rename your fork using this format:

```text
lastname-cpw102-campus-parking
```

If you are working with multiple group members, include each last name:

```text
lastname-lastname-cpw102-campus-parking
```

For example:

```text
smith-jones-cpw102-campus-parking
```

## 2. Make the Repository Public

Make sure your forked repository is **public**.

If you are working with a group, add your group members as contributors to the repository.

## 3. Clone the Repository

Use **GitHub Desktop** to clone the repository to your computer.

Choose a location on your computer where you can easily find the project. The recommended and (likely) default location is 

```
C:/Users/{UserName}/Documents/GitHub
```

## 4. Create a Branch

Before making any changes, create a new branch in GitHub Desktop.

Use a clear branch name, such as:

```text
development
```

Do all project work on this branch.

## 5. Open the Project in Visual Studio Code

From GitHub Desktop, open the repository in **Visual Studio Code**.

Make sure you are working on the branch you created before making changes.

## 6. Begin with `01_initialization`

Open the `01_initialization` folder.

Read the materials in this phase first so you understand the problem you are solving before planning or writing code.

## Project Phases

Complete the project in this order:

```text
01_initialization
02_planning
03_execution
04_testing
05_shipping
```

Most phases contain documents or python files that should be completed before moving to the next phase.

Commit and push your work regularly as you progress through the project.
